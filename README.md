# Portfolio — Antoine Boullanger

Bienvenue sur le dépôt de mon portfolio personnel.

Ce site présente mon parcours, mes compétences techniques et mes projets
dans le cadre de ma recherche d'une alternance en systèmes et réseaux,
avec un intérêt particulier pour le Cloud et la cybersécurité.

## À propos

Je suis étudiant en Bachelor Réseaux, Cloud et Cybersécurité à Sup de Vinci.

Je souhaite développer mes compétences en administration systèmes,
infrastructures réseau, virtualisation et sécurité informatique.

À travers mes projets et mes travaux pratiques, je cherche à approfondir
mes connaissances techniques et à acquérir de l'expérience sur des
environnements informatiques concrets.

## Objectif professionnel

Je recherche une alternance dans les domaines suivants :

- Administration systèmes et réseaux
- Support informatique et assistance technique
- Infrastructure réseau
- Administration Windows Server et Linux
- Virtualisation
- Cloud et cybersécurité

Je souhaite rejoindre une équipe informatique afin de participer à des
projets concrets, développer mes compétences et contribuer au bon
fonctionnement des infrastructures.

## Installation et utilisation

Aucune installation de dépendances n'est nécessaire.

1. Télécharger ou cloner le dépôt.
2. Ouvrir le dossier du projet.
3. Ouvrir `index.html` dans un navigateur web.

Pour modifier le portfolio, éditer les fichiers HTML, CSS et JavaScript
avec un éditeur de code tel que Visual Studio Code.
